# Third-Party Notices

This file is the single place third-party material in this repository is
tracked. It exists before it is needed, so the surface is never ambiguous.

## Currently: none

No third-party source is vendored, ported, or converted into this repository.
Every file here is B44's own work.

Analyzer packages consumed by `B44.Standards` (Meziantou.Analyzer,
Microsoft.CodeAnalysis.BannedApiAnalyzers) are ordinary package dependencies
resolved at build time. They are neither redistributed nor copied into this
source tree, so they create no obligation here; their own licences govern them
wherever NuGet places them.

## If that changes

Obligation-bearing material — anything requiring attribution, licence-text
redistribution, or source disclosure — does not belong in this repository at
all. B44 packages are all rights reserved, so carrying such a file would
contradict the package's own terms. It belongs in a separate repository with
its own `LICENSE` and notices, per the isolation rule in the B44 organization
guidance.

Obligation-free material such as CC0 may live here, but record its source,
date, and what was taken, so provenance can be shown later.
